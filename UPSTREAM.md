# Project origin and attribution

Warp is the Graph Hacks submission built on the open-source peer-to-peer agent mesh originally published as AgentFM by the Agent-FM project.

- Upstream source: <https://github.com/Agent-FM/agentfm-core>
- Warp submission source: <https://github.com/kris70lesgo/warpg>
- License in this repository: Apache License 2.0 (see [LICENSE](LICENSE))

The upstream project supplied the initial libp2p mesh, container worker execution, HTTP/OpenAI-compatible gateway, reputation ledger, Python SDK, and desktop application foundations. The Warp submission adds the FalkorDB-backed connected-data routing, persistent task episodes, shared worker reservations, graph context interface, hackathon documentation, and demo materials.

This attribution does not imply that the upstream maintainers operate Warp, its repository, a public relay, or a hosted service. The Warp repository currently provides source code and a local demo; it has no public release installers or hosted endpoint.
